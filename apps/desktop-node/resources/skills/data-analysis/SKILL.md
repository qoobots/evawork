# 数据分析

## 先说清要回答什么问题

「分析这份数据」不是一个可执行的问题。先问（或先明确）：

- 要回答的业务问题是什么
- 数据有多大量级（几十行还是几百万行——决定用脚本还是直接读）
- 口径：时间范围、过滤条件、去重规则

口径不问清，算出来的数很可能对，但回答不了问题。

## 流程

1. **先看数据的形状**：行数、字段、类型、缺失情况、空值率
2. **再看内容**：取值分布、异常值、重复、格式不一致（日期两种写法、数字带千分位）
3. **然后才计算**。数据没看过的直接算，结论大概率是错的
4. **结论要给数字**：不说「订单很多」，说「7 月 12,431 单，同比 +18%，集中在 3 个渠道」

## 处理脏数据

- **不要默默丢弃**。剔除前先说明剔了多少、什么理由
- 缺失值：有业务含义就标注，不要用 0 填（0 和「没有」是两件事）
- 异常值：先查是不是采集问题，再决定是排除还是保留
- 每个处理步骤都要能被复核——用脚本处理并留下脚本，别手工改完就说结论

## 报告

    结论（3 条以内）
    数据口径与范围
    关键发现（每条带数字）
    处理过的脏数据说明
    建议下一步验证什么

## 别做的事

- 只报「平均数」就下结论——**均值会被极端值骗到**，分布比均值重要
- 看到相关就说因果
- 图表没有单位与时间范围（读者会误读）
