# 对外沟通写作

## 动笔前先确认三件事

1. **对方是谁、什么身份**（客户 / 上级 / 同事 / 陌生人）——决定称呼与分寸
2. **读完要他做什么**——收件人只有一次注意力
3. **不能承诺什么**——涉及时间、金额、范围时，宁可说「需要确认后回复」

## 结构（多数情况够用）

- **第一段：说清目的**。对方读完第一段就知道要不要继续看
- **第二段：给必要信息**（背景、数据、链接）
- **第三段：明确下一步**（要对方做什么、什么时候之前）
- 需要分点的事**用列表**，别写成一大段

## 语气

- 礼貌 ≠ 客气话多。短句 + 明确，比长句 + 敬语更专业
- 有坏消息就直说，先说事实与影响，再说补救。别铺垫、别软化到看不出严重性
- 有诉求就明确提出，不要让对方猜
- 不确定的事标出来（「时间我确认后回复你」），不要含糊过去

## 常见毛病

- 第一段是背景，第三段才有请求 → 对方读不到重点
- 「如有问题请联系」但没给联系方式
- 时间状语含糊：「尽快」「近期」→ 换成具体日期
- 把责任模糊化：「我们这边会跟进」→ 谁跟进、什么时候

## 交付格式

给出**主题 + 正文**两段。正文里不要出现「你好，这是我起草的…」这类元叙述。
