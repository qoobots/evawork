# 前端界面

## 先看现有设计系统，别自创一套

改界面之前**先读项目里的设计规范**（设计令牌、组件库、已有页面）。
本项目的界面规范见 .docs/02_EvaWork Desktop 设计系统规范.md。

- **复用是默认行为**：已有组件、已有间距刻度、已有色板。
- **一致性 > 局部好看**：一个「更好看」但与全站不一致的页面，评价是**不一致**，不是好看。

## 版式

- 先定信息层级，再动样式。层级错了，样式救不回来
- 一屏一个主焦点，次要信息靠位置和留白区分，不要靠再加一层描边
- 间距用刻度（4／8／12／16／24／32），不要随手 13px、17px
- 正文行宽 60–90 字符，行高 1.5–1.75。中文正文比英文更需要限制行长
- 对比度：正文 ≥ 4.5:1，大字 ≥ 3:1。达不到就调色，不要赌用户眼睛好

## 交互

- 每个可点元素都要有 hover／active／focus 三态，**focus 不能去掉**（键盘用户靠它）
- 破坏性操作（删除、清空、覆盖）必须二次确认，并说明**影响范围与能否撤销**
- 长操作要有进度或可取消状态，否则用户只能猜它死没死
- 动效 150–250ms；超过 300ms 就成了等待

## 改界面的纪律

- 用 patch 改样式，不要整文件覆写（会把别人的逻辑一起冲掉）
- 改完**自己看一眼**：元素有没有挤在一起、文字有没有截断、深色模式下对比够不够
- 动布局容易连带影响其它页面，改完顺手 grep 一下共用组件有没有别处在用

工具名以当前可用清单为准（read_file / list_dir / grep / write_file / patch / run_command / todo_write / delegate / load_skill）。
