# EvaWork Desktop · 用户手册

## 1. 它是什么

EvaWork Desktop 是桌面 AI 工作台客户端。实现阶段由 **Electron 壳 + 本地 Python 智能体后端** 组成：界面（Vue）复用原型，数据默认来自本地 Python 后端；后端没起时回退内置示例数据（Mock），界面照常可用。

- 正常使用时会拉起本地 Python 后端（`127.0.0.1:18765`）处理对话与任务；模型调用需配置 API Key（环境变量）。
- 不读写你的业务文件（除非你用"我的文件/本地目录"等显式功能）。
- 输入一句话会生成一条任务记录；在"实现阶段"任务会走真实状态机与流式执行。
- 设置/命令/授权等修改在接入持久化（T-040）前仍可能重启即丢；落地后会保留。

## 2. 装上就能用

1. 安装：运行安装包（electron-builder 产出的 NSIS `EvaWork_0.2.0_x64-setup.exe` 或 MSI），双击安装。
2. 启动：桌面快捷方式或开始菜单里的 EvaWork。窗口默认 1280×820，最小可缩到 960×640。
3. 第一次进来就在"新建任务"页，直接打字即可。程序会自动拉起本地 Python 智能体后端（任务管理器里可见 `python -m evawork` 进程）。

开发者跑源码的方式：

```bash
pnpm install                                              # 前端依赖
pnpm build                                                # 生成前端产物 apps/desktop-ui/dist
cd apps/desktop-py && pip install -r requirements.txt && python -m evawork   # 启动后端（端口 18765）
cd apps/desktop-node && npm install && npm start                              # 启动 Electron 壳（自动拉起后端）
```

## 5. 快捷键

**当前没有全局快捷键。** 界面上也不提供快捷键列表。可用的键盘操作只有浏览器默认行为：输入框回车提交、`Tab` 切换焦点。

## 6. 常见问题

**界面上这些数字是真的吗？**
分两类：管理账户「用量管理」里的**任务数、产物数、趋势与估算 token 是真实统计**（来自本地任务库，token 按字符数/4 估算并已标注）；活跃天数 54、仪表盘热力图等仍是示例数据，出自 `src/data/mock.ts`。

**有积分、套餐或订阅吗？**
没有。EvaWork 面向企业内部员工使用，不计费、无权益档位，"升级权益"与"订阅管理"已下线；用量管理只做使用量记录。

**我做的修改保存了吗？**
在持久化（T-040）落地前：命令、外部应用授权开关、设置改动只在当前进程内存里，关掉程序就没了。落地后这些会写入本地 SQLite 并跨重启保留；具体以版本说明为准。

**会联网吗？**
界面与图标全部内置（内联 SVG 与 CSS 图形），不加载网络字体与图片。但**调用大模型时会联网**：请求只发往你配置的模型服务商（地址/Key 走环境变量，不写死在程序里）。本地渲染层与 Python 后端之间是 `127.0.0.1` 本机通信，不外泄。

**打开是白屏？**
多半是渲染层没拿到后端地址，或前端产物没重新构建：
- Electron 壳启动时会先拉起 Python 后端并等 `/api/health` 就绪，再开窗口；若 Python 未安装依赖，`npm start` 会卡在等待后端。
- 改了 `.vue`/`.css` 必须重跑 `pnpm build`，否则 Electron 加载的是旧 dist。
- 若用纯 `vite preview` 看界面（不进 Electron），渲染层会回退到 Mock 数据，界面仍可用，只是没有真实后端能力。

**点了某个按钮没反应？**
对照 `05_EvaWork Desktop 功能清单与进度.md` 的"静态"清单——那些控件当前是展示用途。这是已知状态，不是崩溃；程序不会报错也不会静默写脏数据。

**管理账户和主界面为什么不是一个风格？**
管理账户（`#/admin/*`）是独立的深色控制台，不带主壳侧栏，这是有意为之的两套视觉。
