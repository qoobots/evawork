# EvaWork Desktop · UI 设计文档

逐页说明界面结构、可交互点与数据来源。**所有数据来自 `src/data/mock.ts`，页面里出现的每一个列表都能在那儿找到同名导出。**

## 0. 全局骨架

```
┌──────────┬────────────────────────────────────────────┐
│ SideNav  │  router-view                               │
│ 186px    │                                            │
│ 品牌区   │                                            │
│ 7 个导航 │                                            │
│ 任务列表 │                                            │
│ 我的菜单 │                                            │
└──────────┴────────────────────────────────────────────┘
   ↑ 主壳（亮色）                浮层：消息 / 升级权益 / 设置
   ↑ `#/admin/*` 走独立深色控制台（AdminLayout），不带侧栏
```

- 路由前缀判断在 `App.vue`：`/admin` 直接渲染 `router-view`，否则套 `SideNav` + 三个浮层。
- 全局状态（模式、任务列表、浮层开关）在 `stores/ui.ts`，刷新即重置。

## 1. 新建任务 `#/`

- **布局（2026-09-30 调整）**：输出在上、输入吸底——任务执行面板与建议区放上方（`.thread` 占满剩余高度），输入区整体沉底（`.dock`，`position: sticky; bottom: 0`）：输入很长滚动时输入框不跑出视线。DOM 顺序＝视觉顺序，键盘/读屏同为"先结果、后输入"。
- **输入区**：单行输入框，回车或点发送按钮提交。空输入时发送按钮禁用。
  - 占位文案随模式变化：Work「帮你整理论文综述、编写 PPT、分析 Excel 等日常工作，输出专业级工作成果。」；Code「描述你要构建的应用，交给 Code 模式」；Design「从想法到设计，生成可执行的原型图」。
- **底部工具条**：
  - `+` 弹出 8 项菜单（上传附件、当前项目的文件、我的产物、命令、插件、技能、飞书文档、飞书通讯录）——**仅展示，无二级面板**。
  - 审批模式：手动审批 / 自动审批 / 完全访问，选中文案回填到按钮。
  - 模型选择：内置 6 个（`builtinModels`），选择后回填；末尾"添加模型"为静态项。
  - 语音按钮（静态）、发送按钮。
- **推荐区**：Work 模式显示 4 条建议（`taskSuggestions`）+ 快捷 chips（`quickChips`）；Design 模式显示 "Design with EVA" 标题 + 3 张建议卡（`designSuggestions`）。

> 提交后的行为：`ui.addTask(text)` 把输入内容作为任务标题插入侧栏列表。**不会发起任何请求，也没有任务详情页。**

## 2. 插件市场 `#/market`

- 页头 + 三张能力专题卡（`pluginFeatureCards`：研究工具 / 内容创作 / 数据分析，配图由 CSS 渐变 + 图标构成）。
- Tab：插件 / 技能。
  - 插件：11 个分类胶囊（`pluginCats`）+ 搜索框（按名称+描述过滤）+ 15 条卡片（`plugins`）。卡片含彩色图标块、名称、描述、操作按钮。
  - 技能：6 个分类胶囊（`skillCats`）+ 20 条卡片（`skills`）；右上角"上传技能"为静态按钮。
- 页头"管理"按钮为静态。

## 3. 模板库 `#/templates`

- Tab：精选 / 收藏。
- 分类胶囊 10 类（`templateCats`）、搜索框、收藏星标，三者**叠加生效**；空结果显示"还没有收藏的模板"或"没有符合条件的模板"。
- 卡片为瀑布流（`columns: 4`），封面是渐变底 + 7 种装饰形态之一，底部一行：HTML 标签 + 标题 + 收藏星。

## 4. 设计系统 `#/design`、`#/design/:id`

- 列表页：内置 8 套（`designSystems`，含 EvaWork / TraeCode / Volcengine / TikTok / Doubao / Apple / Claude / Google），卡片用系统主色画迷你界面缩略图；"自定义"区为空态。
- 详情页顶栏：返回、系统名、四个 Tab、创建副本（静态）。
  - 主题：色板行（10 级色阶，带名称与 hex）或功能令牌行；字体卡（`ds.fonts`）。
  - 组件：组件预览区。
  - 图形：60 个图标名网格（`graphicIcons`），支持关键词搜索。
  - 设计规范：规范说明 + 手机暗色 mock。

## 5. 自动化 `#/automation`

- 页头两个按钮（手动新建 / 在对话中创建）为静态。
- Tab：
  - 已配置：顶部提示条（本地任务在行【商品舆情周报】时运行）+ 2 条配置（`automationConfigs`），每行有更多/设置图标与开关（可切换，仅内存）。
  - 执行历史：空态。
  - 任务模板：8 张卡（`automationTemplates`），三列网格。

## 6. 办公助理 `#/office`

- Hero：蓝紫渐变横幅，左侧标题「从对话开始，把工作交给 EvaWork」，右侧同心圆 + EvaWork 芯片的 CSS 插画。
- 「连接你的通讯工具，即可开始使用」+ 4 个工具（`commTools`）：飞书、微信显示"去绑定"（静态），企业微信、钉钉显示"即将上线"。

## 7. 我的文件 `#/files`

- Tab：本地 / 云端 / 飞书；搜索框（**未接入列表**）；7 个类型胶囊（`fileTypes`，**未接入列表**）；筛选、网格/列表视图图标。
- 列表区为空态：还没有文件 + "去创建"（静态）。

## 8. 管理账户（深色控制台）`#/admin/*`

左侧栏两组：用量管理、账号设置、订阅管理、仪表盘、收藏盒 / 外部应用授权、云端运行环境、MCP、命令、规则。顶栏右侧"下载 TraeCode"与头像。

| 页面 | 内容 |
|---|---|
| 用量管理 | 总积分 4,639.03（sparkle 图标）、通用 2,642 / Work 专属 1,997.03、奖励积分 4 条（`usageRewards`）、用量明细表 3 条（`usageRecords`），今天/7 天/30 天切换与日期区间为静态 |
| 账号设置 | 头像（F）、昵称（Fh）、5 项账号操作（手机号换绑、抖音账号解绑、学生认证、Apple ID、退出登录）、隐私模式（关闭态，静态） |
| 订阅管理 | 当前方案"免费"、升级权益按钮、购买记录空表 + 开票管理 |
| 仪表盘 | 问候语 + 使用天数 54 + 三个标签（小试牛刀 / 单纯型挚友 / 午后突破期）；53×7 活跃热力图（4 级色阶）；代码规模（—）与对话次数（4，含智能体占比条）；最佳拍档 @Agent、模型偏好 @Doubao-Seed-Code |
| 收藏盒 | 空态 |
| 规则 | 规则编辑器：可输入、取消、保存（保存为静态） |
| 命令 | 内置 3 条（review / commit / explain，标"内置"）+ 自定义项；可新建（命令名 + 内容）、可删除，仅内存 |
| 外部应用授权 | 6 个应用（GitHub 默认已连），显示权限范围，开关可切换 |
| 云端运行环境 | 8 个运行时版本（`runtimes`）+ 并发沙箱 3/5、运行时长 62.4/200 小时、存储 4.1/20GB 三条配额 |
| MCP | 6 个 Server（`mcpServers`）+ 搜索框（按名称+描述过滤）、手动添加（静态） |

## 9. 浮层

| 浮层 | 触发 | 内容 |
|---|---|---|
| 消息 | 我的 → 消息 / 铃铛 | 3 条消息（`messages`），每条带时间与操作按钮 |
| 升级权益 | 我的 → ¥29.9 升级权益 / 积分入口 | 用户信息、连续包月（9 折）/单月购买切换、4 档套餐（`plans`）、二维码占位 + 同意协议 |
| 设置 | 我的 → 设置 | 左侧 17 节 + 右侧内容区 |

设置 17 节：账号、用量管理、通用、EVA 移动端、权限审批、MCP、模型、对话流、外部应用授权、浏览器、电脑控制、云端运行环境、工作树、命令、规则与记忆、Beta、关于 EvaWork。其中"权限审批"列出四档（手动审批 / 自动审批 / 完全访问 / 自定义配置）及说明，"模型"列出 18 个提供方（`modelProviders`）。
